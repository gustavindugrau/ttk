# Resumos de chat

Um arquivo por fim de trabalho: o que foi conversado desde o último envio ao GitHub.
Serve para retomar em qualquer máquina sabendo onde parou.

## Nome do arquivo

`AAAA-MM-DD_HHhMM.md` (data e hora do envio). Ex.: `2026-10-18_15h40.md`.

## Formato

```markdown
# AAAA-MM-DD HHhMM · <nome da máquina>

## Conversado
- tópico curto
- tópico curto

## Arquivos alterados
- caminho/do/arquivo: o que mudou

## Próximo passo
- o que fazer na próxima sessão
```

Só tópicos. Sem parágrafos.
